# 경매레이더

**경매 몰라도 괜찮은 공매 큐레이션.** 온비드 공매 물건을 매시간 자동으로 모아 오늘의 픽, 온비드 인기, 이게 이 가격?(이색), 반값, 마감 임박, 최근 낙찰 결과로 보여주고, 물건마다 ‘낙찰 도우미’(예상 낙찰가·시세 비교·위험 신호·최대 입찰가)를 붙인 무료 웹사이트(PWA)예요. 매주 ‘반값 공매 리포트’ 페이지도 자동으로 만들어져 블로그·카톡 공유용 문구를 바로 복사할 수 있어요.

- **비용**: 0원 (GitHub, Cloudflare Pages 무료 요금제, 공공데이터 무료)
- **서버 없음**: GitHub Actions가 매시간 데이터를 받아 정적 사이트를 만들고 Cloudflare Pages에 올려요.
- **인증키 없이도 동작**: 키를 넣기 전에는 예시 데이터로 보여줘요.

## 1. 공공데이터 인증키 받기 (10분)

[공공데이터포털](https://www.data.go.kr)에 가입한 뒤 아래 API를 각각 **활용신청**하세요. 대부분 자동 승인돼요.

| 필수 | API 이름 (포털에서 검색) | 용도 |
|---|---|---|
| ✅ | 한국자산관리공사_차세대 온비드 부동산 물건목록 조회서비스 | 부동산 공매 물건 |
| ✅ | 국토교통부_아파트 매매 실거래가 자료 | 주변 시세 비교 |
| 선택 | 한국자산관리공사_차세대 온비드 동산 물건목록 조회서비스 | 명품·귀금속 등 ‘이색’ 탭 |
| 선택 | 한국자산관리공사_차세대 온비드 차량 물건목록 조회서비스 | 차량 |
| 추천 | 한국자산관리공사_차세대 온비드 순위물건목록 관심물건순위 조회서비스 | ‘온비드에서 지금 뜨는 물건’ |
| 추천 | 한국자산관리공사_차세대 온비드 물건 입찰결과목록 조회서비스 | ‘최근 낙찰 결과’, ‘얼마에 낙찰될까?’ |

모든 API의 이용허락범위가 ‘제한 없음’으로 표시돼 있어요(2026-11 확인). 신청할 때 공공누리 ‘상업적 이용금지’ 표시가 따로 붙어 있지 않은지만 한 번 더 확인하세요.

- 마이페이지 → 인증키에서 **일반 인증키(Decoding)** 를 복사해 두세요. Encoding 키를 넣어도 동작해요.
- ⚠️ 각 API 상세 페이지의 **이용허락범위**를 꼭 확인하세요. 광고를 붙여 수익을 내려면 상업적 이용이 허용돼야 해요. 애매하면 제공기관(한국자산관리공사 디지털시스템실)에 문의하세요.
- 동산·차량·관심순위·입찰결과 API 주소는 코드에 이미 들어 있어요. 활용신청만 하면 자동으로 켜져요(신청 안 한 API는 건너뛰어요).
- (선택) [네이버 개발자센터](https://developers.naver.com)에서 ‘검색’ API 애플리케이션을 만들면 이색 물건에 ‘새 제품 가격’ 비교가 붙어요. 상업적 이용 조건은 네이버 API 이용약관을 확인하세요.

## 2. Cloudflare 준비 (10분)

1. [Cloudflare](https://dash.cloudflare.com)에 가입해요.
2. Pages 프로젝트는 직접 만들 필요 없어요. 첫 자동 배포 때 `auction-radar`라는 이름으로 저절로 만들어져요.
3. 오른쪽 위 프로필 → **API 토큰 → 토큰 생성 → 사용자 지정 토큰**에서 권한을 **계정 · Cloudflare Pages · 편집**으로 정해 토큰을 만들고 복사해요.
4. 대시보드 주소창이나 Workers & Pages 화면 오른쪽에서 **계정 ID**를 복사해요.

## 3. GitHub에 올리고 자동 배포 켜기 (10분)

1. GitHub에서 새 저장소를 만들고 이 폴더 전체를 올려요 (웹에서 ‘Add file → Upload files’로 끌어다 놓아도 돼요).
2. 저장소 **Settings → Secrets and variables → Actions**에서:
   - **Secrets** 탭에 추가
     - `DATA_GO_KR_KEY`: 1단계 인증키
     - `CLOUDFLARE_API_TOKEN`: 2단계 토큰
     - `CLOUDFLARE_ACCOUNT_ID`: 2단계 계정 ID
     - `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: (선택) 네이버 검색 API
   - **Variables** 탭에 추가
     - `SITE_URL`: 사이트 주소 (예: `https://auction-radar.pages.dev`, 도메인을 연결하면 그 주소)
     - `CF_PROJECT`: Pages 프로젝트 이름이 `auction-radar`가 아니면 그 이름
     - `ONBID_GOODS_URL`, `ONBID_CAR_URL`: (선택) 동산·차량 API 요청주소
     - `ONBID_RANK_URL`: (추천) 관심물건순위 API 요청주소
     - `ONBID_RESULT_URL`: (추천) 입찰결과목록 API 요청주소
     - `ONBID_RESULT_PRICE_FIELD`: 낙찰가가 안 잡힐 때만. Actions 로그의 ‘입찰결과 필드’ 목록에서 낙찰가 필드 이름을 넣어요
3. **Actions 탭 → ‘데이터 업데이트 및 배포’ → Run workflow**를 눌러 처음 한 번 실행해요. 이후엔 매시간 자동으로 돌아요.

> GitHub는 저장소에 60일 동안 변경이 없으면 예약 실행을 멈출 수 있어요. Actions 탭에 알림이 뜨면 ‘Enable’을 눌러 주세요.

## 4. 오픈 후 할 일

- 도메인 연결: Pages 프로젝트 → 사용자 지정 도메인.
- 검색 등록: [구글 서치콘솔](https://search.google.com/search-console), [네이버 서치어드바이저](https://searchadvisor.naver.com)에 사이트를 등록하고 `사이트주소/sitemap.xml`을 제출해요.
- `static/terms.html`, `static/privacy.html`의 `[운영자 이메일]`, `[사이트 오픈일]`을 채워요.
- 광고(애드핏·애드센스)나 분석 도구를 붙이면 개인정보처리방침에 내용을 추가해요.

## 내 컴퓨터에서 미리 보기

Node.js 20 이상이 필요해요.

```bash
npm run build                          # 키 없이: 예시 데이터
DATA_GO_KR_KEY=발급키 npm run build     # 실제 데이터
npx serve dist                         # http://localhost:3000
```

## 설정 스위치

| 환경변수 | 설명 |
|---|---|
| `SHOW_PHOTOS=0` | 온비드 사진을 보여주지 않아요 (사진 사용 문제가 생기면 바로 끄기) |
| `SKIP_TRADES=1` | 실거래가 비교를 건너뛰어요 |
| `TRADE_MAX_CALLS` | 실거래가 API 하루 최대 호출 수 (기본 900) |

## 안전장치

- API가 실패하거나 물건이 0건이면 빌드를 멈춰서 **이전 배포가 그대로 유지**돼요. 화면에는 데이터 기준 시각이 보이고, 3시간 넘게 갱신되지 않으면 경고가 떠요.
- 마감이 지난 물건은 자동으로 빠져요.
- 실거래가는 하루에 한 번만 새로 받아 호출 한도를 지켜요.

## 구조

```
scripts/build.mjs    데이터 수집·정리·페이지 생성
functions/img.js     온비드 사진을 대신 불러오는 통로 (Cloudflare Pages Function)
scripts/sample.mjs   예시 데이터
static/              화면 (index, 상세 스크립트, 가이드, 약관, PWA 파일)
.github/workflows/   매시간 자동 실행
dist/                만들어진 사이트 (자동 생성)
```

## 알아둘 점

- 온비드 API 응답 형식은 공개 명세와 다른 사례가 보고돼 있어요(필드가 비어 오는 등). 첫 실행 뒤 Actions 로그에서 수집 건수를 확인해 주세요.
- 관심순위·입찰결과 API는 응답 필드명을 실제로 확인하지 못했어요. 첫 실행 뒤 Actions 로그의 ‘관심순위 필드’, ‘입찰결과 필드’ 줄을 확인하고, 순위나 낙찰 결과가 비어 있으면 그 로그를 보여 주세요.
- 법원경매와 당근·중고나라 같은 중고거래 시세는 공식 API가 없어 넣지 않았어요. 크롤링은 이용약관·권리 문제가 생길 수 있어요. 중고 시세는 외부 검색 링크로만 연결해요.
